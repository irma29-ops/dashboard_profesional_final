# Dashboard Ejecutivo de Ventas 2025

Dashboard interactivo desarrollado con HTML, CSS, JavaScript y Chart.js.

## Funcionalidades

- Indicadores de ingresos, ganancia y unidades vendidas
- Filtros por región, producto y canal
- Gráficas de tendencia mensual
- Análisis por región
- Participación por producto
- Comparación de canales
- Tabla de transacciones
- Diseño responsive

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Chart.js

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Abrir `index.html`.
4. Ejecutar con Live Server.
